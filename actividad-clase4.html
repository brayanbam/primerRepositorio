🪜 1. Arquitectura del Sistema

El sistema está compuesto por tres APIs independientes que se comunican mediante peticiones HTTP:

  • API de Usuarios → Gestiona registro y consulta de usuarios.
  • API de Tareas → Administra las tareas asociadas a cada usuario.
  • API de Notificaciones → Envía recordatorios automáticos vía Telegram.

La comunicación entre servicios se realiza mediante REST (HTTP).

🪜 2. Flujo de Comunicación

Flujo completo del sistema:

  1. Un usuario se registra en la API de Usuarios (POST /usuarios).
  2. Se crea una tarea asociada al usuario (POST /tareas).
  3. El scheduler de la API de Notificaciones consulta periódicamente las tareas pendientes (GET /tareas).
  4. Por cada tarea pendiente, consulta la API de Usuarios para obtener el chat_id (GET /usuarios/<id>).
  5. Se envía la notificación al usuario mediante el Bot de Telegram.

🪜 3. Comunicación entre APIs

Origen Destino Tipo Descripción
API Notificaciones API Tareas REST - GET Solicita lista de tareas pendientes
API Notificaciones API Usuarios REST - GET Obtiene el chat_id del usuario
API Tareas API Usuarios REST Verifica que el usuario exista antes de asociar una tarea

🪜 4. Tipo de Comunicación

Tipo: Síncrona (HTTP REST)

Cada servicio espera la respuesta del otro antes de continuar. Si la API de Usuarios no responde, la API de Tareas no puede asociar la tarea. Si la API de Tareas no responde, la API de Notificaciones no puede enviar recordatorios.

🪜 6. Integración con Telegram

El sistema utiliza un Bot de Telegram para enviar notificaciones automáticas.

  • El usuario debe interactuar previamente con el bot.
  • Se obtiene el chat_id mediante el método getUpdates.
  • El chat_id se almacena en la API de Usuarios.
  • La API de Notificaciones usa ese chat_id para enviar recordatorios.

El intervalo_notificacion define cada cuántos minutos se enviará el recordatorio.

🪜 8. Propósito del Sistema

  • Facilitar la gestión de tareas personales y académicas.
  • Automatizar recordatorios sin intervención manual.
  • Mantener trazabilidad completa sin eliminar registros.
